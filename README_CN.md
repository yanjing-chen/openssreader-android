# OpenSSReader Android 1.0.1

独立 Android 项目，内置 Mozilla GeckoView 浏览器书城及本地 PDZ 阅读器。保留原有 `book://` 下载队列、PDF 解码与书架标签。书架根据实际窗口宽度自适应：窄屏使用分类抽屉和全宽书架，宽屏保留侧栏。

- 当前版本：`1.0.1`，versionCode `10001`，包名 `org.openssreader.android`。
- 本地编译：`bash ./BUILD_ANDROID_6800H.sh`（Android SDK 37.0 + Build Tools 36.0.0、JDK 17）。
- 自动构建：`.github/workflows/android.yml`。
- 正式发布：`.github/workflows/release.yml`，通过私密签名密钥构建发布版 APK 和 SHA256 校验文件。
- 应用设置新增：检查 GitHub Release 更新、下载并校验 APK、使用 Android 系统安装器安装；以及“关于”版本信息。
- 界面移除预览版/引擎说明、下载页说明、扫描书架说明和功能范围说明；保留有效功能。

**发布之前务必阅读 [RELEASE_GUIDE_CN.md](RELEASE_GUIDE_CN.md) 的签名迁移提示。** 新正式签名与旧 debug 安装签名不同，不能直接覆盖安装，切勿在没有备份时卸载旧版。

**手机布局：** 窗口内容宽度小于 600dp 时显示全宽书架，点击“分类”打开抽屉；600dp 及以上保留平板分栏。分类与自建标签仍可选择，长按标签可重命名或删除。搜索框使用单行占位文本，避免竖排。状态栏使用适合浅色背景的深色图标。当前为待实机验证的自适应候选。

**高清书籍封面（1.0.1）：** 书城之外的本地书架会优先读取 PDZ 原生封面；没有封面则使用完整 PDF 的第一页。缺失真实封面时会在 PDF 解码完成后自动使用高清首页；已有真实封面即使来源较小，也不会被误换成书内页。缩略图根据设备的物理像素密度生成，最大约 1600px 宽，PNG 无损缓存保存在应用私有缓存目录（有 96MB 上限），不会修改或重新编码原 PDZ/PDF。下载解码尚未完成且 PDZ 首页又不属于可直接读取的图片格式时，封面在解码完成后才可出现。旧的 400/512px 缩略图逻辑已删除。

**阅读翻页（1.0.1）：** 单页和双页模式取消横向滑动翻页，点击阅读画面左侧 28% 返回上一页、右侧 28% 打开下一页，点击中间显示/隐藏工具栏。长按、拖动、多指和放大后的平移不会触发翻页；保留双指缩放与底部页码/上一页/下一页按钮。连续模式保留原本的上下滚动，并支持点页面左右边缘切换相邻页。

## 阅读器简洁分区菜单（1.0.1 候选）

前言、目录、正文下拉菜单只显示分区名称，不显示括号页码；实际跳转页码保持不变。菜单项和按钮采用更紧凑的间距，手动缩放按钮已取消，保留双指缩放和左右轻点翻页。


## 1.0.1 从本地推送并发布

本包不包含 Git 仓库历史。请保留原有 `.git` 工作树，运行：

```bash
# 在本完整源码目录执行；目标参数是原来包含 .git 的仓库
bash ./PUSH_FROM_6800H.sh /path/to/原有Git仓库
# 确认 main 分支 GitHub Actions 已成功之后：
bash ./RELEASE_1_0_1_6800H.sh /path/to/原有Git仓库
```

发布使用原有签名 Secrets 和 tag `v1.0.1`，不会修改 `v1.0.0`。不要重新生成 keystore。
